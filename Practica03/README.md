# Práctica 3: Boceto de Modelo Canvas con Achify

## Descripción

En esta práctica se realizó el diseño de un **Business Model Canvas interactivo** mediante el uso de **Archify**, tomando como objeto de estudio una aplicación multiplataforma utilizada en la vida cotidiana.

Para el desarrollo de la actividad se seleccionó **Bitwarden**, una plataforma multiplataforma orientada a la administración segura de contraseñas, credenciales e información sensible. A partir de sus características, servicios, usuarios y modelo de negocio, se estructuró un primer *prompt* para generar el modelo Canvas.

Posteriormente, se revisó el resultado obtenido y se realizó una segunda versión del *prompt* con instrucciones más específicas, buscando mejorar la distribución visual, el contenido, la interactividad y la representación de los nueve bloques que conforman el **Business Model Canvas**.

El resultado final fue generado como una experiencia web interactiva en formato HTML, permitiendo explorar cada uno de los bloques mediante tarjetas seleccionables, paneles de información, efectos visuales, navegación interna y relaciones entre los diferentes elementos del modelo.

## Aplicación Multiplataforma Seleccionada

### Bitwarden

**Bitwarden** es una plataforma de administración de contraseñas y credenciales que permite almacenar, generar, administrar y sincronizar información de acceso de forma segura.

Su principal función es ayudar a los usuarios a mantener sus credenciales organizadas y disponibles desde diferentes dispositivos mediante un sistema de almacenamiento protegido y sincronización.

Bitwarden puede utilizarse en diferentes sistemas y plataformas, entre ellos:

* **Windows**
* **Linux**
* **macOS**
* **Android**
* **iOS**
* **Aplicación Web**
* **Google Chrome**
* **Mozilla Firefox**
* **Microsoft Edge**
* **Safari**
* **Extensiones para navegadores**

La posibilidad de utilizar una misma cuenta y acceder a las credenciales desde diferentes sistemas y dispositivos permite considerar a Bitwarden como una solución **multiplataforma**.

Además, la plataforma dispone de diferentes modalidades de servicio orientadas a usuarios individuales, familias, equipos de trabajo y organizaciones.

## Interactividad del Modelo

Una de las principales mejoras realizadas durante la práctica fue transformar el **Business Model Canvas** en una experiencia interactiva.

El modelo generado mediante **Archify** permite explorar la información utilizando diferentes componentes.

### Tarjetas Interactivas

Cada uno de los nueve bloques puede seleccionarse para mostrar información adicional.

Al posicionar el cursor sobre una tarjeta:

* Se aplica una animación.
* Se resalta el bloque.
* Se modifica ligeramente su posición.
* Se muestra visualmente que puede seleccionarse.

Al seleccionar una tarjeta:

* Se muestra información ampliada.
* Se presentan ejemplos relacionados con Bitwarden.
* Se explican las funciones del bloque.
* Se resaltan otros bloques relacionados.

El modelo permite visualizar relaciones entre diferentes componentes del Canvas.

Por ejemplo:

**Propuesta de Valor** se relaciona con:

**Fuentes de Ingresos** se relaciona con:

## Proceso de Ingeniería de Prompts

Durante la práctica se utilizaron diferentes iteraciones del *prompt* con el objetivo de mejorar progresivamente el resultado generado.

### Prompt Inicial

La primera versión solicitó de manera general la creación de los nueve elementos del **Business Model Canvas** para Bitwarden.

El resultado permitió establecer la estructura principal del modelo, aunque algunos elementos presentaban información demasiado general y la representación obtenida era principalmente estática.

### Revisión

Después de analizar la primera generación se identificaron las siguientes oportunidades de mejora:

* Especificar con mayor detalle cada bloque del Canvas.
* Diferenciar correctamente los segmentos de clientes.
* Ampliar los canales utilizados por la plataforma.
* Representar con mayor claridad el carácter multiplataforma de Bitwarden.
* Especificar las principales fuentes de ingresos.
* Mejorar la organización visual del Canvas.
* Incorporar tarjetas, iconos y elementos gráficos.
* Agregar interactividad.
* Incorporar efectos de `hover`.
* Permitir seleccionar los bloques.
* Mostrar información ampliada.
* Visualizar relaciones entre diferentes bloques.
* Crear una vista resumen y una vista detallada.
* Evitar párrafos demasiado extensos.
* Evitar información estadística o financiera no comprobada.

### Prompt Mejorado

La segunda versión incorporó instrucciones detalladas relacionadas con:

* Contenido esperado para cada bloque.
* Organización visual del modelo.
* Uso de tarjetas y componentes gráficos.
* Distribución tradicional del Business Model Canvas.
* Características multiplataforma.
* Segmentación de usuarios.
* Interactividad mediante HTML, CSS y JavaScript.
* Paneles de información.
* Relaciones entre bloques.
* Navegación interna.
* Flujo de valor.
* Modelo Freemium.
* Diseño responsive.
* Accesibilidad.
* Restricciones relacionadas con información inventada.
* Presentación orientada a un contexto académico.

Esto permitió obtener un modelo más completo, organizado, visual e interactivo.

## Conclusión

El desarrollo de esta práctica permitió aplicar técnicas de **ingeniería de prompts** para generar y mejorar un **Business Model Canvas interactivo** mediante **Archify**.

La iteración del *prompt* permitió comprobar que proporcionar contexto, restricciones, estructura, requisitos visuales e instrucciones de interactividad mejora considerablemente la calidad de los resultados generados por herramientas de inteligencia artificial.

Asimismo, el análisis de **Bitwarden** permitió identificar los principales elementos que conforman su modelo de negocio, incluyendo su propuesta de valor, segmentos de clientes, recursos, actividades, socios, canales, costos y fuentes de ingresos.

Su disponibilidad en diferentes sistemas operativos, dispositivos, navegadores y aplicaciones demuestra además su carácter **multiplataforma**, permitiendo a los usuarios acceder y administrar sus credenciales desde distintos entornos.

Finalmente, la incorporación de elementos interactivos permitió transformar el Business Model Canvas tradicional en una experiencia web más visual, dinámica y fácil de explorar, manteniendo al mismo tiempo un enfoque académico y profesional.
